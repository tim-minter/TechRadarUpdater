# TechRadarUpdater


# How to run


npm init -y
npm install express
Put your architecture.json in ./data/
run node server.js


Simple one page web app that lets you view and edit a typical Technology Radar json source file.

## Installation

Clone the repo then run the following commands in the repo folder.

```bash
npm init -y
npm install express
run node server.js
```
